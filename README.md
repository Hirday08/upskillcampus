# Student Management System

## Internship Project

A console-based Student Management System developed in Python as part of the Upskill Campus / USC-UCT internship program.

## Project Overview

The Student Management System is a Python-based console application designed to manage student records efficiently.

The system allows users to add, view, search, update, and delete student records. It also provides a grade calculation feature and stores student information permanently using JSON file handling.

## Features

- Add new student records
- View all student records
- Search students using Student ID
- Update student information
- Delete student records
- Calculate student grades based on marks
- Input validation
- Error handling
- Persistent data storage using JSON
- Menu-driven console interface

## Technologies Used

- Python
- JSON
- File Handling
- Exception Handling

## Student Information

The system stores:

- Student ID
- Student Name
- Age
- Course
- Year
- Marks

# Python-Based Student Management System

A console-based Student Management System developed using Python as part of the Upskill Campus Python Learning Internship in collaboration with The IoT Academy and UniConverge Technologies Pvt. Ltd. (UCT).

## Project Overview

The project aims to provide a simple and efficient way to manage student records using Python. The system will allow users to add, view, search, update, and delete student information through a menu-driven interface.

## Planned Features

- Add student records
- View all student records
- Search for a student
- Update student information
- Delete student records
- Calculate and display grades
- Store student records using file handling
- Input validation

## Technology Used

- Python
- File Handling
- Functions
- Conditional Statements
- Loops
- Lists and Dictionaries
